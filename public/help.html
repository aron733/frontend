Trouve rapidement une réponse à ta question

Bienvenue dans le centre d'aide officiel de VOKYVO. Cette page répond aux questions les plus fréquentes sur l'application : inscription, messagerie, groupes, assistant Vokyvo AI, actualités, sécurité, confidentialité et suppression de compte. Si tu ne trouves pas ta réponse, contacte le support à support@vokyvo.com ou via le bot Telegram @vokyvo_bot.

Démarrage & inscription

Qu'est-ce que VOKYVO ?
VOKYVO est une plateforme de communication intelligente qui réunit messagerie, groupes, assistant IA, actualités et visioconférence dans un même espace. Elle est pensée pour l'Afrique de l'Ouest, avec un slogan simple : « Everything. Everyone. Everywhere. »
Comment créer un compte ?
Ouvre l'application, clique sur « Inscription », remplis le formulaire (prénom, nom, email, âge) et valide avec le code OTP envoyé par email. Tu peux aussi t'inscrire avec Google OAuth en un clic.
Quel âge minimum pour s'inscrire ?
L'âge minimum est de 16 ans. Entre 16 et 18 ans, une autorisation parentale est obligatoire. À partir de 18 ans, l'inscription est libre.
Puis-je m'inscrire avec Google ?
Oui. Sur l'écran de connexion, clique sur « Continuer avec Google ». Si c'est ta première connexion, tu devras compléter ton profil (numéro, pays, âge, sexe).
Comment vérifier mon email ?
Un code OTP à 6 chiffres est envoyé à ton adresse email lors de l'inscription. Saisis-le dans l'application pour activer ton compte. Si tu ne le reçois pas, vérifie tes spams ou demande un nouveau code.

Connexion & mot de passe

J'ai oublié mon mot de passe
Sur l'écran de connexion, clique sur « Mot de passe oublié ». Un code de réinitialisation te sera envoyé par email. Saisis-le, puis choisis un nouveau mot de passe.
Comment changer mon mot de passe ?
Va dans Profil → Sécurité → « Changer mon mot de passe ». Tu devras confirmer via un code envoyé par email, puis saisir ton nouveau mot de passe.
Comment activer la double authentification (2FA) ?
Va dans Profil → Sécurité → 2FA. Scanne le QR code avec une application comme Google Authenticator, puis saisis le code généré pour activer la protection.
Pourquoi je suis déconnecté automatiquement ?
Pour des raisons de sécurité, ta session expire après une période d'inactivité. Reconnecte-toi simplement avec ton email et mot de passe. Si tu utilises l'application sur plusieurs appareils, chaque session est indépendante.

Profil & paramètres

Comment modifier ma photo de profil ?
Va dans Profil → Modifier le profil → clique sur « Changer la photo ». Sélectionne une image depuis ta galerie (max 5 Mo, formats JPEG, PNG, WebP ou GIF).
Comment changer mon numéro de téléphone ?
Va dans Profil → Modifier le profil. Sélectionne ton indicatif pays (82 pays disponibles) puis saisis ton nouveau numéro. Le formatage est automatique.
Comment obtenir le badge vérifié ?
Le badge vérifié est réservé aux comptes publics, créateurs de contenu et partenaires. Tu peux en faire la demande via Profil → Demander le badge. Chaque demande est étudiée manuellement.
Puis-je changer mon nom d'utilisateur ?
Oui, tu peux modifier ton prénom et ton nom à tout moment dans Profil → Modifier le profil. Ton adresse email, en revanche, n'est pas modifiable.

Messagerie privée

Comment envoyer un message privé ?
Ouvre l'onglet Messages, clique sur le bouton « + » puis recherche l'utilisateur par son nom ou son email. Une conversation privée s'ouvre instantanément.
Les messages sont-ils en temps réel ?
Oui. VOKYVO utilise WebSocket pour la synchronisation instantanée. Si tu ne vois pas un message arriver, vérifie ta connexion internet et redémarre l'application si nécessaire.
Puis-je envoyer des photos, vidéos ou audios ?
Oui. Dans une conversation, clique sur l'icône trombone pour joindre un fichier (photos, vidéos, documents) ou sur l'icône micro pour enregistrer un message vocal.
Comment savoir si mon message a été lu ?
Les indicateurs de lecture (ticks) sont en cours de déploiement sur la messagerie privée. Ils afficheront : envoyé, reçu, puis lu.
Comment supprimer un message ?
Appuie longuement sur le message concerné, puis sélectionne « Supprimer ». Le message sera retiré de ta conversation. La suppression est définitive.
Pourquoi mes messages ne s'affichent pas ?
Vérifie ta connexion internet. Si le problème persiste, ferme et rouvre l'application. Les messages sont synchronisés via WebSocket en temps réel. Si tu utilises un VPN ou un réseau restrictif, le WebSocket peut être bloqué.

Groupes

Comment créer un groupe ?
Dans l'onglet Messages, clique sur « Créer un groupe », donne-lui un nom, une description et une photo, puis ajoute des membres. Tu deviens automatiquement administrateur.
Combien de membres par groupe ?
Les groupes VOKYVO n'ont pas de limite stricte de membres. Pour des raisons de performance, nous recommandons de rester sous 500 membres par groupe.
Comment nommer un modérateur ?
Ouvre le groupe, va dans les paramètres, puis sélectionne un membre et choisis « Nommer modérateur ». Les modérateurs peuvent supprimer des messages et bannir des membres.
Comment quitter un groupe ?
Ouvre le groupe, va dans les paramètres et clique sur « Quitter le groupe ». Si tu es le créateur, tu dois d'abord nommer un autre administrateur ou supprimer le groupe.
Comment demander l'accès à un groupe privé ?
Dans l'onglet Découvrir, trouve le groupe privé et clique sur « Demander l'accès ». Un modérateur examinera ta demande et pourra l'accepter ou la refuser.

Vokyvo AI (assistant)

Qu'est-ce que Vokyvo AI ?
Vokyvo AI est l'assistant intelligent intégré à VOKYVO. Il peut répondre à tes questions, t'aider dans tes devoirs, résumer des textes, traduire, et même générer des images.
Comment générer une image avec l'IA ?
Dans le chat Vokyvo AI, dis simplement « Génère une image de [sujet] ». L'IA te demandera des précisions si le sujet est flou, puis générera l'image via Cloudflare FLUX.
L'IA peut-elle se tromper ?
Oui. L'IA est un outil d'aide et peut produire des informations inexactes ou obsolètes. Vérifie toujours les réponses importantes (santé, droit, finance) auprès de sources fiables.
Quelles sont les limites d'utilisation de l'IA ?
Pour garantir un service fluide à tous, Vokyvo AI applique des limites : 30 messages par minute, 10 OCR par minute et 5 générations d'images par heure. Ces limites peuvent évoluer.
L'IA garde-t-elle mes conversations ?
Tes conversations avec Vokyvo AI sont stockées dans ton historique pour te permettre de les retrouver. Elles ne sont ni vendues ni utilisées à des fins publicitaires. Tu peux les supprimer à tout moment.

Cours & OCR

Comment fonctionne l'OCR ?
Prends une photo d'un texte (devoir, page de livre, note) et VOKYVO extrait le texte automatiquement. Tu peux ensuite demander à l'IA de l'expliquer ou de le corriger.
Puis-je utiliser VOKYVO pour mes devoirs ?
Oui, VOKYVO est un outil d'aide scolaire. L'IA peut expliquer des concepts, corriger des exercices et t'aider à réviser. Attention : elle ne remplace pas ton propre travail, et les réponses doivent toujours être vérifiées.

Actualités (News)

D'où viennent les actualités ?
Les actualités proviennent de flux RSS de médias partenaires (Google News, LeFaso, Burkina24, etc.). VOKYVO agrège ces flux et les affiche dans l'onglet Actus.
Comment changer de catégorie d'actualités ?
Dans l'onglet Actus, utilise les onglets horizontaux en haut (Flash, Finance, Dev, Burkina, etc.) pour changer de rubrique. La section Burkina fusionne LeFaso et Burkina24.
Comment partager un article ?
Clique sur l'icône de partage (le carré avec la flèche) sur n'importe quelle carte d'article. Tu peux partager sur WhatsApp, Telegram, X, Facebook, copier le lien ou partager via VOKYVO.
Puis-je sauvegarder un article ?
La sauvegarde d'articles est une fonctionnalité prévue dans une prochaine mise à jour. En attendant, tu peux copier le lien ou le partager vers toi-même.

Newsletter

Comment m'inscrire à la newsletter ?
Va sur vokyvo.com, descends jusqu'au formulaire newsletter et saisis ton email. Tu recevras un email de confirmation.
Comment me désabonner de la newsletter ?
Clique sur le lien de désabonnement en bas de chaque email, ou rends-toi sur vokyvo.com/desabonnement. Ton adresse sera immédiatement retirée de la liste.

Visio & appels

Comment lancer un appel vidéo ?
Dans une conversation, clique sur l'icône caméra en haut à droite. La visioconférence VOKYVO permet jusqu'à 5 participants simultanés.
Pourquoi l'appel vidéo ne fonctionne pas ?
Vérifie que tu as autorisé l'accès à la caméra et au micro dans les paramètres de ton téléphone. Vérifie aussi ta connexion internet : une bonne qualité vidéo nécessite au moins 1 Mbps.

Sécurité & confidentialité

Mes données sont-elles en sécurité ?
Oui. Tes communications sont chiffrées en transit (HTTPS/TLS), tes mots de passe sont hachés (PBKDF2), et nous ne vendons jamais tes données. Consulte notre politique de confidentialité pour les détails.
VOKYVO utilise-t-il un chiffrement de bout en bout ?
Non, pas encore. Les messages sont chiffrés en transit, mais pas de bout en bout. Cette fonctionnalité est à l'étude pour une version future.
Où sont hébergées mes données ?
VOKYVO est hébergé chez InterServer (USA), avec Cloudinary (USA) pour les médias et Backblaze B2 pour les sauvegardes chiffrées. L'IA utilise Groq (USA).
Comment voir mes dernières connexions ?
Va dans Profil → Sécurité. Tu verras les 10 dernières connexions avec l'IP, l'appareil et la date. Si tu ne reconnais pas une connexion, change immédiatement ton mot de passe.
Comment télécharger mes données (RGPD) ?
Va dans Profil → Mes données → « Télécharger mes données (JSON) ». Le fichier contient ton profil, tes conversations et tes groupes. C'est ton droit à la portabilité (RGPD art. 20).
Que faire si mon compte est piraté ?
Change immédiatement ton mot de passe via « Mot de passe oublié », active la 2FA dans Profil → Sécurité, puis vérifie tes dernières connexions. Si nécessaire, contacte le support à support@vokyvo.com.

Suppression de compte

Comment supprimer mon compte ?
Trois façons : (1) App : Menu → Quitter → Supprimer mon compte (immédiat). (2) Web : vokyvo.com/supprimer-compte (immédiat). (3) Email : support@vokyvo.com (sous 72h).
Que deviennent mes données après suppression ?
Ton compte est immédiatement désactivé. Les sauvegardes sont purgées sous 30 jours. Certaines données peuvent être conservées plus longtemps si la loi l'exige (obligations comptables, litiges).
Puis-je récupérer un compte supprimé ?
Non. La suppression est définitive. Si tu souhaites revenir sur VOKYVO, tu devras créer un nouveau compte avec une nouvelle adresse email.

Abonnement & VOKYVO+

VOKYVO est-il gratuit ?
Oui. Toutes les fonctionnalités essentielles (messagerie, groupes, IA, actualités, visio) sont gratuites. Une offre premium VOKYVO+ est en préparation.
Qu'est-ce que VOKYVO+ ?
VOKYVO+ est l'offre premium en préparation. Elle offrira des fonctionnalités avancées (badge, thèmes, limites IA augmentées). Aucune date de sortie n'est encore annoncée.

Problèmes techniques

L'application plante au démarrage
Force l'arrêt de l'application puis relance-la. Si le problème persiste, désinstalle et réinstalle depuis GitHub Releases. Vérifie que tu utilises la dernière version.
Je ne reçois pas les notifications
Vérifie que les notifications sont autorisées dans les paramètres de ton téléphone (Paramètres → Applications → VOKYVO → Notifications). Vérifie aussi que le mode Ne pas déranger n'est pas activé.
L'application est lente
Vérifie ta connexion internet. Ferme les applications en arrière-plan et redémarre VOKYVO. Si le problème persiste, contacte le support avec le modèle de ton téléphone et la version d'Android.
Comment signaler un bug ?
Tu peux signaler un bug via le bot Telegram @vokyvo_bot, ou par email à support@vokyvo.com. Décris précisément le problème, joins une capture d'écran si possible, et indique ton modèle de téléphone et ta version d'Android.
