VOKYVO v3.38.0 : Social, VideoFeed et API publique

Produit 28 octobre 2026 · Par Aron VOKOUMA

La version 3.38.0 de VOKYVO est en ligne. C'est la plus grosse mise à jour depuis le lancement de l'application. En 48 heures, j'ai construit un fil Social complet, un lecteur vidéo plein écran (VideoFeed), un algorithme de recommandation, des deep links, et ouvert une API publique aux développeurs.

Voici ce qui a changé.

1. Le fil Social arrive sur VOKYVO

Jusqu'ici, VOKYVO était une messagerie avec une IA et des documents scolaires. Maintenant, c'est aussi un réseau social.

Le fil Social permet de :

  • Publier des posts texte avec un fond dégradé (6 couleurs disponibles).
  • Joindre plusieurs photos ou vidéos à un même post (multi-médias).
  • Réagir avec 6 émotions différentes : 👍 J'aime, ❤️ J'adore, 😂 Haha, 😮 Wow, 😢 Triste, 😡 En colère.
  • Commenter chaque post (modale "bottom sheet" façon Instagram).
  • Partager un post via l'API native du téléphone (navigator.share).
  • Suivre des Pages (comptes thématiques).

Chaque post obtient un code court unique, ce qui génère un lien partageable : vokyvo.com/p/aBcD12. Le même lien fonctionne sur le web et dans l'APK Android.

2. VideoFeed : les Reels de VOKYVO

Le VideoFeed est un lecteur vidéo plein écran, inspiré de TikTok et Instagram Reels :

  • Scroll vertical avec scroll-snap (une vidéo à la fois).
  • Vidéos muettes par défaut (l'utilisateur active le son d'un clic).
  • Boutons d'action à droite (like, commentaire, partage).
  • Skeleton loader pendant le chargement.

Chaque vidéo du fil Social peut basculer en mode VideoFeed. C'est le même contenu, présenté différemment selon l'intention de l'utilisateur.

3. Algorithme de recommandation

J'ai écrit un algorithme de tri dans un fichier dédié (algorithme.py). Le score d'un post est calculé comme ceci :

score = (likes × 2) + (commentaires × 3) + (partages × 5)

Le score est appliqué sur une fenêtre de 7 jours. Résultat : les posts récents et engageants remontent, les anciens posts sans interaction descendent. C'est simple, mais c'est un vrai départ pour un fil intelligent.

4. L'API publique VOKYVO

La grande nouveauté de cette version : l'API est ouverte aux développeurs.

Deux types de clés sont disponibles depuis la Console développeur :

  • vky_... pour publier automatiquement sur le Social.
  • vok_... pour interroger Vokyvo AI.

Exemple : publier un post depuis n'importe quel script :

curl -X POST https://api.vokyvo.com/api/social/publier/ \
  -H "Authorization: Bearer vky_votre_cle" \
  -H "Content-Type: application/json" \
  -d '{"texte": "Mon premier post automatique !"}'

Et poser une question à l'IA :

curl -X POST https://api.vokyvo.com/api/ia/chat/ \
  -H "Authorization: Bearer vok_votre_cle" \
  -H "Content-Type: application/json" \
  -d '{"message": "Explique-moi la Charte de Kurukan Fuga."}'

Les rate limits sont clairs : 50 requêtes par heure et 200 par jour, par compte, toutes clés confondues.

La documentation complète est ici : vokyvo.com/console-doc.

5. Les corrections de la session

Cette version n'est pas seulement une pile de nouveautés. J'ai aussi corrigé un certain nombre de bugs accumulés :

  • Décorateurs manquants sur plusieurs vues Django (commentaires, likes) → erreurs 500 silencieuses, corrigées.
  • Badge MODO invisible dans les groupes : le backend ne renvoyait pas la liste des modérateurs, corrigé.
  • Barre d'action de groupe réservée à l'admin : maintenant accessible aux modérateurs aussi.
  • Deep links /p/<code> qui renvoyaient une 404 React à cause du routeur maison, corrigés.
  • Miniatures vidéo qui ne remontaient pas du backend, corrigées (génération Cloudinary .jpg).
  • Pull-to-refresh ajouté au fil Social pour l'APK Android.

6. Les prochaines étapes

VOKYVO grandit vite, et cette version n'est qu'une étape. Voici ce qui arrive dans les prochaines semaines :

  • Application Android : la nouvelle version de l'APK intégrant le fil Social et le VideoFeed sera disponible très bientôt.
  • Expérience de chat améliorée : de nouvelles fonctionnalités de messagerie pour vous faire gagner du temps.
  • Fil d'actualité personnalisé : encore plus de contenus pertinents pour l'Afrique de l'Ouest.
  • Notifications en temps réel : soyez alertés instantanément des nouvelles activités sur vos Pages et vos posts.

7. Ce que ça représente

VOKYVO, c'est aujourd'hui plus de 30 000 lignes de code, réparties entre :

  • Un backend Django complet (95+ endpoints REST).
  • Un frontend React 19 packagé en APK Android via Capacitor.
  • Un serveur WebSocket dédié (Daphne) pour le temps réel.
  • Un bot Telegram interactif.
  • Une infrastructure VPS sécurisée (SSH par clé, UFW, Fail2ban, Cloudflare Full Strict).
  • Une IA multi-providers (7 en cascade) avec RAG local sur l'histoire africaine.

Tout ça, construit par une seule personne. Un lycéen de 17 ans, à Ouagadougou.

VOKYVO n'a pas besoin d'être parfait pour exister. Il a besoin d'être vrai, utile, et de grandir un peu chaque semaine.
